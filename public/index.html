    여행 공유

    승인된 사용자의 이메일을 입력하면 그 사용자의 “공유받은 여행”에 표시됩니다. 공유받은 사람도 장소를 추가·수정·삭제하며 함께 편집할 수 있어요. (여행 삭제와 공유 관리는 만든 사람만 가능)

    Google Maps API 키 입력

    구글 계정 연동 없이 API 키만 있으면 됩니다. 키는 이 브라우저(localStorage)에만 저장되며 어디로도 전송되지 않습니다.

    1. Google Cloud Console에서 프로젝트 생성 후 Maps JavaScript API, Places API (New), Geocoding API, Routes API 활성화
    2. 사용자 인증정보 → API 키 생성
    3. 키 제한 → HTTP 리퍼러에 사용할 주소(예: localhost:8000/*) 지정 권장
